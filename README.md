# Water Quality Monitoring - Mechanical Design 

> Hardware and mechanical engineering files for a remote-controlled (RC) catamaran designed for real-time river water quality monitoring.

---

## Overview
This repository contains all mechanical documentation, manufacturing exports, and 3D CAD models for the water quality monitoring vessel. The physical platform is designed to safely carry sensor payload (pH, DO, Turbidity, EC, ORP, Temp), an STM32 microcontroller enclosure, and heavy lithium batteries through variable river conditions.
